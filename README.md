# orbix-lpr-releases

This repository is dedicated to publishing the built binary releases for the Orbix LPR project.

Its purpose is to make release artifacts readily available to the public in a consistent and easily accessible location, while keeping the distribution of compiled binaries separate from the primary project development workflow.

## Overview

- Hosts public release binaries for Orbix LPR
- Makes downloadable artifacts available for users and testers
- Organizes builds in a centralized location for convenience and access

## Note

This project exists solely to distribute prebuilt binaries associated with the Orbix LPR project. It is not intended to replace the source repository or serve as the main development codebase for the application.
